Chat commands like !voice hello are read aloud with the VoiceStudio voice you link to that command.

Download the relay

1. OBS browser source

In OBS: Sources → + → Browser → paste this URL. No size needed; the page is invisible. Tick "Control audio via OBS" if you want it on its own mixer track.

The VoiceStudio OBS Connector Relay must be running. Download the relay (Windows, macOS, Linux). Default is this PC on port 8787.

2. VoiceStudio

Default is this PC. If VoiceStudio runs on another computer in your network, enter that computer's address, for example http://192.168.1.20:3900. Chrome will ask permission to contact it. The relay must be able to reach that address too; if OBS sees it under a different address, add &endpoint=http://ADDRESS:3900 to the end of your OBS URL.

3. Commands and voices

Commands: max 8 characters. A ! is added in front automatically.

VoiceStudio must be running to load voices and models.

4. Behavior

Longer messages are cut off after this many characters. Default 190.

After a viewer's command is accepted, any further commands from that same viewer are ignored (not queued) for this many seconds. 0 = off. Applies per viewer name and platform, and also to mods.

5. Read all chat (optional)

Lines starting with ! are still commands. Needs relay 0.0.7 or newer. Chat lines are read with the voice settings below; commands keep their own voices.

Voices come from "Load voices from VoiceStudio" in section 3.

Leave on "same as the line" to use one voice for everything. With a separate voice, the relay prepares both parts and then plays them one after the other.

When more are waiting, the oldest are dropped.

Everything typed in chat gets spoken on your stream: use blocked words, ignored names and a cooldown, and consider your platform's rules.

6. Updates

Open the download page

This only asks GitHub which version is the newest (a public page). Nothing about you or your settings is sent. Nothing is installed automatically: you update by hand.

How to update

  1. Download the new zip from the download page above.
  2. Click Show where this extension is installed below. Chrome opens the details page of this extension. The folder is listed there as Source.
  3. Unzip the new download so that its VoiceStudio-OBS-Connector folder replaces the old one: extract it into the folder that contains the old VoiceStudio-OBS-Connector folder and choose Replace (overwrite all). Or copy everything inside the new folder into the old one and overwrite the old files. Keep the same folder: another folder counts as a different extension and your settings would not come with it.
  4. On the Chrome extensions page, click the reload icon (circular arrow) of this extension. Your settings are kept.

Or open it yourself: type chrome://extensions in the address bar, switch on Developer mode, click Details on VoiceStudio OBS Connector and look for Source. It shows the full folder path on Windows, macOS and Linux. This extension's ID is .

7. Backup: export and import your settings

Saves everything you set up (commands, voices, speed, models, addresses, options and the ID of your OBS URL) in one small file, and loads it back. Use it before you delete or move the extension folder, or to move to a new computer or browser. Chrome keeps the settings together with the extension, so a deleted extension loses them.

Export saves what you last saved (click Save first if you just changed something). Import fills this page with the settings from the file, replacing what is shown; check them, then click Save to keep them. The file contains your addresses and your OBS ID, so keep it private.
